# Mindful Meditation website

A responsive static website styled to follow the supplied black-and-white wireframe screenshot, using the Mindful Meditation content from the supplied HTML file.

## Files
- `index.html` — page structure and content
- `style.css` — screenshot-inspired layout and responsive styles
- `script.js` — mobile navigation, search, demo account dialog and calendar

## Preview
Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.

## Publish with GitHub Pages
1. Create a repository on GitHub.
2. Upload these four files into the repository's root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

## Before using the site publicly
- Replace `LOGO` with your actual logo or brand name.
- Replace the sample contact email `hello@example.com`.
- The images currently load from Unsplash; replace them with your own image files if desired.
- The login/sign-up dialog is a front-end demonstration only. It does not create accounts or store credentials.
- Membership buttons are demonstrations; no payment processing is connected.
- The calendar displays dates but does not currently contain saved events.
